{{ projectName }} serves as a dynamic playground for exploring and showcasing cutting-edge web development projects. The cornerstone of {{ projectName }} is an interactive CV platform. The concept is simple yet powerful:

The initial idea was to just turn my CV into a website to showcase my web development skills. But the developer in me couldn't just create a static CV website. So it eventually turned into a user driven platform, where users can create and customize their own professional CV profile.
